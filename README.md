# 🛒 KDV Automation

[![Python Version](https://img.shields.io/badge/python-3.8+-blue.svg)](https://python.org)
[![Selenium](https://img.shields.io/badge/selenium-4.15+-green.svg)](https://selenium.dev)

> Автоматизация заказов в интернет-магазине KDV Online

## 📋 Описание

Скрипт для массового добавления товаров в корзину KDV Online из Excel-файла.

## 🚀 Возможности

- ✅ Автоматическая авторизация на сайте KDV
- ✅ Обработка товаров из Excel-файла
- ✅ Установка количества товаров
- ✅ Обновление статуса заказов в Excel

## 📦 Установка

```bash
git clone https://github.com/krasir-dev/kdv-automation.git
cd kdv-automation
pip install -r requirements.txt
